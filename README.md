> Senior Penguin Relocation Therapist

## How it works

`main.ts` (Node) writes the single entry title to `/output/entry.txt` as UTF-8 text. It guards the length (1–60 characters), rejects whitespace-only or multi-line text, and throws if the title falls outside the gate.

```sh
node main.ts
```
